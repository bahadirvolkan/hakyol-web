# Ramazan 2027 İmsakiye Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Altı dilde, şehir bazlı, her gece yenilenen Ramazan 2027 imsakiye sayfaları üretmek.

**Architecture:** Saf tarih ve vakit seçimi `lib/imsakiye.js` içinde; statik HTML üretimi `build-imsakiye.js` içinde tutulur. Dünya vakitleri mevcut `build-world.js` hesaplayıcısını, Türkiye sayfaları kapsama varsa Diyanet satırını yoksa kalibre edilmiş Turkey hesabını kullanır.

**Tech Stack:** Node.js 22, yerleşik `Intl`, mevcut `js/adhan.min.js`, statik HTML/XML.

**Spec:** Kullanıcının 2026-11-22 tarihli “Ramazan 2027 imsakiye sayfaları” görev metni.

## Global Constraints

- Yalnız bu worktree; commit/push/deploy yok.
- Yeni npm bağımlılığı, emoji, Google Fonts CDN, çerez/izleme yok.
- Kalıcı URL'lerde yıl yok; başlık ve bağlantı metninde 2027 var.
- Üretilen dizinler gitignore'da; mevcut sitemap dosyaları kullanılır.

## Review Focus

- Umm al-Qura ay sınırı ve 29 günlük Ramazan.
- Build tarihi Ramazan öncesi/içi/sonrası durum metni.
